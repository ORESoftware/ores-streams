# Retirement checklist

- [x] Machine-readable legacy status exists.
- [x] Human migration guidance exists.
- [x] Active ORESoftware consumer inventory is empty as of 2026-09-14.
- [x] New mutable dependencies are forbidden by policy.
- [x] Historical artifacts are preserved.
- [x] Validation checks lifecycle/docs/package consistency.
- [ ] No compatibility release has been required for 180 consecutive days.

The final unchecked condition is time-based and does not block compatibility-only operation; it only gates archive-only treatment.
